# v0.4.15 지원 범위

직전 배포판은 v0.4.14입니다. 제품 경로와 전체 회귀 근거의 기준 커밋은 `4f14abe50c5bd99bef0ae0ce58c758b1370156f7`입니다. 버전 표기와 이 문서 이후의 원격 설치 결과는 최종 배포 SHA에 연결합니다. [PR #37](https://github.com/wooyj-1217/kmp_agent/pull/37)

| 흐름 | 검증 범위 |
| --- | --- |
| 설치·초기화·업데이트 | 고정 후보의 원격 설치와 v0.4.14에서 후보로 직접 업데이트를 확인했습니다. |
| 요구·단계 준비 | 빈 프로젝트의 기획 등록과 샘플별 독립 요구사항 QA 15개 항목을 확인했습니다. |
| 디자인·시안·검토 | Android·iOS에서 제목과 0건·3건 화면을 독립 검토했습니다. |

| QA·검증 | 각 경로에서 플랫폼별 실제 단위 테스트 2건과 최종 독립 제품 QA를 통과했습니다. |
