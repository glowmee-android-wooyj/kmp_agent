# v0.4.12 지원 현황

VERSION **0.4.12**. 직전 배포 [v0.4.11](v0.4.11.md)의 커밋은 `3102129e2b4993787376fec749209deb32b7561a`이다. [PR #34](https://github.com/wooyj-1217/kmp_agent/pull/34)의 계약 전환을 포함한다. 최종 SHA와 원격 검증은 [GitHub Release](https://github.com/wooyj-1217/kmp_agent/releases/tag/v0.4.12)에서 확인한다.

기존 기술 계약에 묶인 작업이 새 기술 제안의 승인 뒤 멈췄다면, [전환·복구 절차](../requirement-lineage.md#승인된-기술-계약을-기존-시도에-전환)에 따라 정확한 native 승인과 후보를 연결한다. 원래 질문·응답·checkpoint·시도를 보존하고 기술 입력을 교체한다. 전환 후 새 계약에 맞춰 검증하고 기존 시도를 재개한다. 중단된 트랜잭션은 공식 복구 명령으로 전환 전 상태를 복원할 수 있다.

| 흐름 | 지원과 조건 |
| --- | --- |
| 설치·init·update | [설치 안내](../installation.md)에서 명시 태그를 선택한다. 실제 훅 활성은 새 세션에서 확인한다. |
| 기획 생성·검토 | 기존 승인과 비기술 요구를 보존한다. |
| 디자인·시안·검토 | 기존 P/D/API 기준을 유지한다. |
| 개발 작업 생성·실행 | 원래 작업의 동결 기술 계약과 관련 입력을 전환한다. |
| 실패 반환·보완·재검증 | 중단 journal 복구와 같은 시도 재개를 지원한다. |
| 변경 감지·개발·재검증 | 전환 후 현재 계약과 현재 코드의 실행 근거를 요구한다. |
| 산출물·실행·로그·사용량 | 원래 baseline과 승인 기록, 전환 증거를 보존한다. |
| 개발 작업 병렬 실행 | 전환 시 독점 작업 소유권과 이전 executor 종료를 확인한다. |
| 하네스 결함·PR | 검증 후 명시 승인으로 배포한다. 실제 제품 적용은 별도 확인한다. |

v0.4.3~v0.4.11 설치본은 프로젝트 루트에서 `rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.12`를 사용한다. v0.4.2 이하는 사용자 터미널에서 새 bootstrap으로 전환한다.
