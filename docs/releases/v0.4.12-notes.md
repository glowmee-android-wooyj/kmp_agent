# v0.4.12 — 이미 승인한 기술 계약으로 전환

새 기술 제안을 먼저 승인한 뒤 기존 계약 입력 때문에 멈춘 작업을 복구할 수 있습니다. `transition-approved-contract`는 기존 native 승인과 checkpoint를 보존하며 승인된 기술 입력을 연결합니다. 중단된 전환은 `recover-contract-transition`으로 복구하고, 변경된 계약에는 새 검증 근거를 사용합니다.

[PR #34](https://github.com/wooyj-1217/kmp_agent/pull/34) · [지원 범위](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.12/docs/releases/v0.4.12.md) · [v0.4.11 대비 변경](https://github.com/wooyj-1217/kmp_agent/compare/v0.4.11...v0.4.12)

v0.4.3~v0.4.11 설치본은 프로젝트 루트에서 다음 명령을 사용합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.12
```

신규 설치와 v0.4.2 이하 전환은 [설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.12/docs/installation.md)를 따릅니다. 업데이트 후 [계약 전환 절차](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.12/docs/requirement-lineage.md#승인된-기술-계약을-기존-시도에-전환)를 사용합니다.
