# v0.4.9 — QA 이미지 전달과 공식 이슈 해소 복구

v0.4.8 이후 PR #29를 포함한 패치 릴리스입니다. 기존 검증 폴더의 명시 QA 이미지를 격리 실행 모델에 전달하고, 담당 단계에서 공식 CLI로 이슈를 해소할 수 있습니다. 최종 배포 SHA·원격 검증 결과는 게시 본문에서 확정합니다.

## v0.4.8 대비 수정

- `verification/` 아래 등록한 이미지도 실제 바이너리 복사본을 native `--image`에 전달합니다. 원본·복사본의 등록 해시와 경계를 모델·검증 명령 실행 전후에 검사하고 packet/report에 출처를 남깁니다.
- `task --operation resolve-issue`를 공식 설치 CLI에 연결합니다. 담당 작업의 활성 review·이슈별 관찰·디자인 캡처 검사를 유지합니다.
- 이슈 해소 시 실제 현재 산출물의 존재·경계·내용 해시를 재검사해 변경된 파일을 옛 보고서로 해소하지 못하게 합니다.

명령은 수동 호출하며 명령 내부에서 계약을 검사합니다. 이슈 해소 뒤에도 정상 단계 검토를 통과해야 합니다. 제품을 자동 업데이트·승인·재개하지 않습니다.

## 설치·업데이트

신규 설치는 게시된 v0.4.9 bootstrap을 명시 선택합니다. 임시 경로와 제품 Git 루트는 실제 사용할 경로로 바꾸세요.

```sh
rtk proxy git clone --depth 1 --branch v0.4.9 git@github.com:wooyj-1217/kmp_agent.git /tmp/kmp-agent-bootstrap
rtk proxy python3 /tmp/kmp-agent-bootstrap/bootstrap.py install --source git@github.com:wooyj-1217/kmp_agent.git --ref v0.4.9 --target /path/to/product
```

v0.4.3~v0.4.8 설치본의 프로젝트 루트에서는 다음 단일 명령을 사용합니다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.9
```

기존 source를 사용하므로 다른 셸 명령·`--source`·`--target`을 덧붙이지 않습니다. v0.4.2 이하는 사용자 터미널의 새 bootstrap으로 전환합니다. 선택 SHA·runtime과 새 세션의 훅 신뢰·활성을 확인하세요. 기존 QA 결과·원장·승인을 자동 이전하거나 재판정하지 않습니다. 실제 제품 업데이트와 재개는 별도입니다.

[0.4.9 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.9/docs/installation.md)

## 검증 범위와 알려진 제한

동일 구현의 핵심 회귀 **16개 PASS**, 별도 코드 검토와 Python 3.13 전체 회귀 **948개 실행**을 확인했습니다. 전체 회귀의 환경 오류 **8건**은 로컬 HTTP 포트 bind 권한 거부이며 기준 main에서도 동일하게 재현했습니다. assertion failure는 없지만 전체 PASS로 간주하지 않습니다. 최종 후보의 설치·init·재설치·v0.4.8 업데이트와 원격 태그/SHA 검증 결과는 게시 본문에서 확정합니다.

이미지는 합성 adapter로 실제 파일 전달을 확인했습니다. 실제 모델의 시각 판단·설치본 Codex 훅·전체 모델 E2E·공통 예제·실제 제품 업데이트/인수는 NOT_RUN입니다. 개인 원문·제품 자료·원본 로그는 공개하지 않습니다.
