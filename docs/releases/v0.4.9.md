# v0.4.9 지원 현황

VERSION **0.4.9**, 태그 **v0.4.9**의 제공 범위다. 직전 실제 배포 [v0.4.8](v0.4.8.md), 커밋 `2b1b01c858ce386f30dcf2bca3ce1bad42455d83` 이후 [PR #29](https://github.com/wooyj-1217/kmp_agent/pull/29)를 포함한다. 준비 기준은 머지 커밋 `9adcd8ab77c960e8cff68e209f89b40d2de824a3`이며 최종 SHA·원격 태그 검증·게시 결과는 [GitHub Release](https://github.com/wooyj-1217/kmp_agent/releases/tag/v0.4.9)에서 확정한다.

## v0.4.8 이후 수정

- `configure-qa`에 명시 등록한 이미지가 일반 복사에서 제외되는 `verification/` 아래에 있어도, 등록한 바이너리만 격리 작업공간의 `qa-tools/image-inputs/`에 복사하고 실제 경로를 native `--image`에 전달한다. 전체 검증 트리는 복사하지 않는다.
- 원본·복사본을 등록 SHA-256과 대조하고 모델 실행 전후 및 검증 명령 뒤에 다시 검사한다. 누락·변경·프로젝트 경계 이탈·symlink 입력은 거부한다. packet/report의 `image_materializations`에 원본·복사 경로와 해시를 남긴다.
- 공식 설치 CLI에 `task --operation resolve-issue`를 연결한다. 담당 작업의 활성 review, 현재 제출 산출물, 이슈별 관찰과 디자인 이슈의 캡처 조건은 유지한다.
- 이슈 해소 시 원장에 저장된 해시뿐 아니라 실제 현재 산출물의 존재·프로젝트 경계·바이트 SHA-256도 재검사한다. 수정 후 옛 보고서로 해소하는 경로를 차단한다.

[QA 입력·이슈 해소 계약](../qa.md)과 [단계 반환·보완 흐름](../stage-readiness.md)을 따른다. 이슈 해소와 정상 단계 검토 통과는 별개다. 실제 모델의 이미지 이해나 제품 시각 QA PASS를 이미지 전달 성공으로 대신하지 않는다.

## 설치·전환

신규 설치는 [설치 안내](../installation.md)의 v0.4.9 bootstrap을 명시 선택한다. v0.4.3~v0.4.8 설치본은 기존 source를 재사용하는 단일 관리 명령을 사용한다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.9
```

다른 명령·`--source`·`--target`과 결합하지 않는다. v0.4.2 이하는 사용자 터미널의 새 bootstrap으로 전환한다. 선택 SHA·runtime과 새 세션의 훅 신뢰·활성을 확인한다. 이전 QA 결과·질문·원장을 자동 변경하지 않는다. 입력·산출물이 바뀐 QA는 현재 원본으로 재구성해 재검증하며 기존 실패·승인·캡처 근거는 보존한다. 실제 제품 업데이트·재개는 별도다.

## 검증 범위

2026-11-16 PR #29 제출 커밋 `e001e9048760077b9e0892aa3acc1f65eb9bcb39`의 핵심 이미지 전달·설치 CLI 회귀 **16개 PASS**와 별도 코드 검토를 확인했다. 동일 구현의 Python 3.13 전체 회귀는 **948개 실행, assertion failure 0, 환경 오류 8건**이다. 오류는 모두 샌드박스의 로컬 HTTP 포트 bind 권한 거부이며 기준 main에서도 같은 테스트의 동일 오류를 재현했다. 전체 PASS로 표시하지 않는다. 릴리스 후보와 런타임·테스트 내용 해시를 대조해 이 결과의 적용성을 확인한다.

후보 버전·문서의 영향 검사, 신규 설치·init·재설치·v0.4.8→v0.4.9 update 및 최종 태그/SHA의 원격 설치 결과는 Release 게시 본문에서 확정한다. 합성 격리 이미지 시험은 실제 `--image` 파일 인자를 읽어 확인하며 실제 모델의 시각 판단을 검증하지 않는다. 실제 설치본 Codex 훅·전체 모델 E2E·공통 예제·실제 제품 업데이트/인수는 **NOT_RUN**이다. 개인 원문·제품 자료·검증 원본은 공개하지 않는다.
