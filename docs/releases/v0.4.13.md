# v0.4.13 지원 현황

VERSION **0.4.13**. 직전 배포는 [v0.4.12](v0.4.12.md)다. [PR #35](https://github.com/wooyj-1217/kmp_agent/pull/35)의 명령 사전 검사 한도와 지연 진단을 포함한다. 배포 SHA와 원격 검증 결과는 [GitHub Release](https://github.com/wooyj-1217/kmp_agent/releases/tag/v0.4.13)에서 확인한다.

공식 명령의 사전 검사 한도는 기본 60초이며 `--preflight-timeout`으로 지정할 수 있다. 단계별 시간과 실제 프로세스 생성 여부를 기록한다. 작업자 스레드의 협력적 제한은 차단된 커널 I/O가 반환된 뒤 기한을 확인한다. OS 프로세스 생성·등록과 실제 명령 실행에는 별도 경계가 적용된다. [실행 정책](../execution-policy.md#명령-실행-전-검사와-지연-진단)을 따른다.

| 흐름 | 지원과 조건 |
| --- | --- |
| 설치·init·update | [설치 안내](../installation.md)에 따라 명시 태그를 선택한다. 실제 훅 활성은 새 세션에서 확인한다. |
| 기획 생성·검토 | 기존 요구 승인과 현재 native 원문의 검증을 유지한다. |
| 디자인·시안·검토 | 기존 P/D/API 계약 및 승인 입력을 사용한다. |
| 개발 작업 생성·실행 | 승인된 명령의 실행 전 검사에 기한과 단계별 진단을 적용한다. |
| 실패 반환·보완·재검증 | 자식 생성 전 확실히 중단된 경우 같은 시도로 재시도한다. 소유권이 불확실하면 공식 복구를 사용한다. |
| 변경 감지·개발·재검증 | [파일 관측 범위](../sequential-evidence.md#자동-관측과-역할-책임)에 따라 생성물을 선별하고 검증 소유권 검사를 유지한다. |
| 산출물·실행·로그·사용량 | 명령 요청과 실제 프로세스 생성 이벤트를 각각 기록한다. |
| 개발 작업 병렬 실행 | 작업자 스레드에서는 협력적으로 기한을 검사하며 생성 직전에 다시 확인한다. |
| 하네스 결함·PR | 최종 커밋에서 검증하고 명시 승인으로 배포한다. 제품 설치 반영은 프로젝트에서 확인한다. |

v0.4.3~v0.4.12 설치본은 프로젝트 루트에서 `rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.13`을 사용한다. v0.4.2 이하는 새 bootstrap으로 전환한다.
