# v0.4.11 — 중단 후 같은 시도의 빌드·테스트 재개

v0.4.10에서 작업을 재개해도 상위 로그가 종료된 경우 빌드·테스트 명령이 `run already finished`로 거부됐다. v0.4.11의 `continue-command-run`은 기존 작업·승인·시도를 보존하면서 새 명령 로그를 연결한다. 정상적으로 반환한 빌드 뒤에는 소유권 해제와 자식 프로세스 종료를 확인해 같은 시도에서 테스트를 실행할 수 있다.

## 설치·업데이트

신규 설치는 [v0.4.11 설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.11/docs/installation.md)를 따른다. v0.4.3~v0.4.10 설치본은 프로젝트 루트에서 다음 명령을 사용한다.

```sh
rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.11
```

v0.4.2 이하는 사용자 터미널에서 v0.4.11 bootstrap을 사용한다. 올바른 설치 버전과 실제 Codex 훅 활성 상태를 확인한 뒤 [재개 절차](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.11/docs/interruption-recovery.md#작업은-재개됐지만-상위-명령-run이-종료된-경우)를 따른다.
