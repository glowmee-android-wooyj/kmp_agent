# v0.4.15

기존 승인 범위의 관리 빌드와 테스트가 사전 검사 중 멈추는 문제를 줄였습니다.

- 명령 실행 전에 승인 대기 상태와 활성 시도를 중복 조회하는 경로를 정리했습니다. 기본 사전 검사 제한은 60초입니다.
- 단계 보완 한도에 도달하면 승인된 추가 보완을 실행할 수 있습니다.
- 실제 제품의 신규 착수와 업데이트·재개를 정식 배포 검증에 포함합니다.

프로젝트 루트에서 `rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.15`로 업데이트합니다. [설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.15/docs/installation.md)

기본 설정에서 Android·iOS KMP 샘플의 신규 착수와 v0.4.14 직접 재개를 확인했습니다. 두 경로에서 관리 빌드, 플랫폼별 실제 단위 테스트 2건, 독립 요구사항·제품 QA가 통과했습니다.
