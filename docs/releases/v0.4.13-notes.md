# v0.4.13

## 이번 버전 요약

승인된 명령이 실행 전에 지연될 때 어느 검사에서 기다리는지, 실제 프로세스가 생성됐는지 확인할 수 있습니다. 사전 검사는 기본 60초이며 `--preflight-timeout`으로 조정할 수 있습니다.

## v0.4.12 대비 변경

- 단계별 지연과 타임아웃을 기록하고 프로세스 생성 직전에 기한을 확인합니다.
- 생성 전에 안전하게 중단된 명령은 기존 승인과 작업 시도를 유지한 채 재시도할 수 있습니다. 소유권이 불확실한 경우 공식 복구 흐름을 사용합니다.
- 현재 native 원문 검증을 유지하면서 승인 확인과 파일 관측의 반복 작업을 줄였습니다.

## 설치·업데이트

설치된 프로젝트에서 `rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.13`을 실행합니다. 최초 설치와 v0.4.2 이하에서의 전환은 태그에 고정된 [설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.13/docs/installation.md)를 따릅니다.

작업자 스레드의 기한 확인은 협력적으로 동작합니다. OS의 프로세스 생성·등록과 명령 실행 시간은 사전 검사 한도의 적용 범위 밖입니다. [지원 범위](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.13/docs/releases/v0.4.13.md)

## 검증 범위

배포 커밋과 원격 태그 검증 결과는 게시 시 확정합니다. 실제 제품 KMP 빌드·인수와 신뢰된 Codex 세션의 훅 전달은 별도 검증 범위입니다.
