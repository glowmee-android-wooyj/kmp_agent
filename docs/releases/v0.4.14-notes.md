# v0.4.14

통합 잠금이나 작업 원장 잠금의 자체 대기 한도를 넘기면 CLI 오류와 명령 사전 검사 로그에서 잠금 경로, 대기 시간, 요청 작업과 마지막 보유자 기록을 확인할 수 있습니다.

## v0.4.13 대비

- 상대 경로로 프로젝트를 지정해도 잠금 시간 초과 진단을 제공합니다.
- 보유자 기록은 마지막 획득 또는 해제 상태입니다. 기록이 없거나 읽을 수 없으면 `unknown`으로 표시합니다.
- 명령 사전 검사 기한이 먼저 끝나면 사전 검사 단계의 시간 초과를 보고합니다.

## 설치·업데이트

기존 설치는 프로젝트 루트에서 `rtk proxy python3 .kmp-agent/agent.py update --ref v0.4.14`로 업데이트합니다. 처음 설치하거나 v0.4.2 이하에서 전환할 때는 [설치 안내](https://github.com/wooyj-1217/kmp_agent/blob/v0.4.14/docs/installation.md)를 따릅니다.

## 검증 범위

배포 커밋과 원격 태그 설치·업데이트 검증 결과는 게시 시 확정합니다. 실제 제품 KMP 빌드와 신뢰된 Codex 세션의 훅 동작은 적용 프로젝트에서 확인합니다.
