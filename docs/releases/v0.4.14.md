# v0.4.14 지원 범위

[v0.4.13](v0.4.13.md) 이후 통합 잠금과 작업 원장 잠금의 시간 초과 진단을 개선한다. 오류와 사전 검사 로그에 잠금 경로, 대기 시간, 요청 작업과 마지막 보유자 기록을 표시한다. 기록된 PID는 현재 OS 잠금 보유자를 인증하지 않는다.

태그 게시 후 설치된 프로젝트에서 `python3 .kmp-agent/agent.py update --ref v0.4.14`를 실행한다. 실제 제품 빌드와 Codex 훅 검증은 적용 프로젝트에서 별도로 확인한다.

## 지원 흐름과 검증 범위

[v0.4.13의 지원 흐름](v0.4.13.md)을 기준으로 이번 변경의 영향을 대조했다.

| 흐름 | 이번 버전에서 확인한 범위 |
| --- | --- |
| 설치·init·update | 후보 SHA로 신규 설치·init·재설치와 v0.4.13 관리 업데이트를 재실행했다. 런타임 식별 정보 및 제품 파일을 확인했다. |
| 요구·단계 준비 | 잠금 진단 변경과 기존 단계 계약을 대조했다. 실제 제품 요구와 단계 준비는 별도 적용 범위다. |
| 디자인·시안·검토 | 기존 디자인 계약과 승인 입력을 사용한다. 새 제품 시안 검토는 미실행이다. |
| 개발·명령 실행 | 고정 SHA 업데이트 뒤 승인된 계약 전환과 사전 검사 타임아웃 재시도를 재실행했다. |
| QA·검증 | 동일 설치 업그레이드 시험에서 기존 승인으로 빌드·테스트 명령 실행과 승인 범위 밖 작업의 거부를 확인했다. |
| 실패 반환·보완·재검증 | 잠금 경합 회귀 시험에서 상대 경로, 대기 시간, 마지막 보유자, 해제 기록을 확인했다. |
| 완료·제출·인계 | 고정 SHA 업데이트 시험에서 기존 시도의 제출 흐름을 재실행했다. 실제 제품 인수는 별도다. |
| 산출물·실행·로그·사용량 | 관리 업데이트 후 기존 실행 로그와 훅 설정 파일 보존을 확인했다. 신뢰된 Codex 세션의 실제 훅 호출과 사용량 수집은 미검증이다. |
| 하네스 결함·PR | [PR #36](https://github.com/wooyj-1217/kmp_agent/pull/36)의 범위와 지침을 검토했다. 최종 커밋과 원격 태그 검증은 [GitHub Release](https://github.com/wooyj-1217/kmp_agent/releases/tag/v0.4.14)에 기록한다. |
